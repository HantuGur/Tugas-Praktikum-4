# Tugas Praktikum 4 - Layout/Tata Letak Responsif

Portfolio pribadi yang dibuat untuk memenuhi Tugas Praktikum 4 mata kuliah Web
(Layout/Tata Letak Responsif). Dibuat pakai HTML, CSS, sama JavaScript biasa,
tanpa framework/library apapun sesuai ketentuan tugas.
